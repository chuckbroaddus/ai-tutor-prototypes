Skill Galaxy · visual prototypes

Research prototypes for the RPG skill tree (spec §8.3, §16.7, Decision Q17). All learner values are example data (Math, Chemistry alcohols and a fuller Spanish (ACTFL levels) sketch, four mostly greyed subjects, two cross-system links). Local only; not wired to the app. Dark mode, matches Design 2.

A · fully 3-D

A · Free 3-D galaxy (Three.js)

Your original idea, literally: orbit camera, planets in depth, labels that appear by camera distance. Includes a “Top-down” button to show what flattening does. Built to find out where 3-D hurts.

 B · flat 2-D

B · 2-D orbital map with semantic zoom

Same planetary-system metaphor on a flat plane. One continuous zoom: galaxy → system → tier cluster → skill detail, with the content of each level changing (semantic zoom). Strongest keyboard and reduced-motion story.

 C · hybrid (recommended)

C · 3-D galaxy overview, flat 2-D systems

A gently tilting 3-D galaxy of subjects (few objects, no occlusion problem); click a system and it becomes the flat map from B. Keeps the “wow” and the legibility. Idle drift: planets slowly orbit their suns (3-D galaxy and flat system map) once you have been still for about 4 s; any pointer, key, wheel or touch pauses it, and it stays still while a skill is selected or the panel or list is open. Off under reduced motion.

Shared by all three: planet encoding (ring fill = mastery, size = mastery, ✓ mastered, ↻ review suggested), dashed link = path open, solid link = learning, hidden link shown only when you select a locked skill; click a skill for prerequisites, required level (Solid 55%) and your current level; “List view” is the non-visual equivalent (KM-020).

Three.js r170 (MIT) is vendored in vendor/, so the pages work offline, as the Tauri app will need.
